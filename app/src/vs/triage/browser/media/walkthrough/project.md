## A Triage project

```
smart-fan/
  triage.toml        the project: boards, links between domains
  firmware/          your code
  electronics/       KiCad schematic and board
  mechanical/        FreeCAD enclosure and mechanism
  simulation/        scopes and scenario tests
```

The KiCad and FreeCAD files stay openable in KiCad and FreeCAD.
