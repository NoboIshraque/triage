# sim/: Triage's simulation runner

`@triage/sim` (ROADMAP P3): everything of the simulation that runs in Node, around
the Rust kernel (`crates/triage-sim-node`, loaded as `triage_sim.node`).

| File | What |
|---|---|
| `src/avr.ts` | The AVR unit: an ATmega328P (Arduino Uno, Nano) in avr8js as the kernel's host. Pin drives as timed events with early return, ADC conversions synced on demand, USART (serial monitor), TWI (I²C devices at transaction level), SPI |
| `src/generated/avr-decoder.ts` | avr8js's instruction bodies behind a 64K dispatch table (generated by `scripts/avr-decoder.mjs`; checked against avr8js on every opcode) |
| `src/ssd1306.ts`, `src/font.ts` | The SSD1306 OLED and reading the text it shows |
| `src/project.ts` | A project as a device: `.triage/links.json`, `simulation/parts.toml`, `environment.toml`, scopes |
| `src/runner.ts` | A run: the kernel, the AVR unit and the displays (the app's sim engine, the CLI and the tests use it) |
| `src/scenario.ts` | Scenario YAML v0 and its checks |
| `src/firmware.ts` | Arduino firmware builds with avr-gcc and the Arduino AVR core |

```sh
node crates/triage-sim-node/build.mjs --mujoco   # the addon (after node engines/mujoco/build.mjs)
pnpm --filter @triage/sim test                    # firmware tests need avr-gcc: TRIAGE_REQUIRE_TOOLCHAIN=1 in CI
node cli/dist/bin.js test examples/smart-fan      # the Smart Fan's scenarios
```

Raspberry Pi Pico (rp2040js), the QEMU and Renode adapters, the Pi Python bridge
and the network gateway arrive with P4 and P7.
