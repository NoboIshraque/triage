# Provenance

This directory is the **reverse-engineer-anything** skill (skill version 44,
220 tools), copied unchanged from the bundle that `rea setup --client
claude_code` installed from REA **6.7.0**, built from `noboishraque/rea`.

- Upstream project: REA, "Reverse Engineer Anything" (https://github.com/morluto/rea).
- License: MIT, Copyright (c) 2026 morluto. See the upstream `LICENSE`.
- The skill's commands are pinned to `rea-agents@6.7.0`. Keep the MCP server or
  CLI you use at the same version, or regenerate this copy with
  `rea setup --skill-client claude_code` after upgrading.

The skill supplies instructions only. It does not register the REA MCP server;
see `CLAUDE.md` for how to connect it in a session.
