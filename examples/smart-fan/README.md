# Smart Fan (example project)

The walkthrough device of [PLAN §3](../../docs/PLAN.md): a thermistor reads the
room temperature, an Arduino Uno drives a fan through a MOSFET with PWM, shows
the temperature on an OLED and lights a status LED (D2 on D13: on while the fan
runs, blinking when it's hot), and the fan sits in a printed enclosure.

| Folder | Domain | Filled in by |
|---|---|---|
| `firmware/` | Code | the firmware: the fan curve, the Mode button, the OLED (`src/oled.cpp`), the status LED |
| `electronics/` | Electronics | the KiCad project (schematic and board, Arduino Uno shield) |
| `mechanical/` | Mechanical | the fan's rotor (`fan.FCStd`, P2-2) and the enclosure from the board (P2-4) |
| `simulation/` | Simulation | `parts.toml` (the fan on J1, the OLED on J3, the rotor), `environment.toml`, a saved scope and six scenarios (P3) |
| `.triage/` | (Triage) | `links.json`, the link graph Triage writes from the schematic (the simulation reads it) |

Open this folder in Triage: the Triage sidebar shows the four domains. The Sim
tab's **Run** runs it and **Run all scenarios** runs its scenarios (CI runs the
same with `node cli/dist/bin.js test examples/smart-fan`).

The KiCad files and the enclosure are generated by `scripts/examples/` with
Triage's own engines; the **Examples** workflow (`.github/workflows/examples.yml`)
regenerates them in CI and uploads them to commit.
